# NexTarget App v0.2.0 — 2025-09-28

Cette note décrit l'état historique de la v0.2.0. Les instructions de configuration qu'elle contenait ne sont plus valables ; consulter la documentation courante.

## Ajouts

- Rappels essentiels Sécurité et Tir sur l'accueil.
- Export des sessions vers un dossier choisi.
- Suppression des objectifs atteints.
- Animation de splash personnalisée.
- Script de build APK versionné.

## Changements et corrections

- Rebranding NexTarget et nommage des APK.
- Neutralisation du double splash natif.
- Messages d'erreur réseau plus précis.
- Correction d'un débordement dans la liste des objectifs.
- Permission réseau ajoutée au build Android release.

## Note de sécurité historique

Cette version permettait encore l'injection d'une clé Mistral dans le client. Ce comportement a été entièrement supprimé en v0.5.0 avec NT-061. Il ne doit pas être réintroduit.
