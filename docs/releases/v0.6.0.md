# NexTarget (app) v0.6.0 — 2026-09-02

Râtelier d'armes personnel, autocomplétion, compteur de tirs par arme et
persistance serveur PostgreSQL Neon.

## Carnet de tir
- **NT-008** — Râtelier d'armes personnel : CRUD simple (ajout, renommage,
  suppression) dans Paramètres > Préférences Tir. Noms obligatoires et
  uniques après normalisation (espaces/casse ignorés). Le renommage,
  confirmé explicitement, se propage aux sessions prévues et réalisées
  correspondantes, de façon atomique (rollback complet en cas d'échec). La
  suppression ne modifie jamais les sessions existantes. Export JSON inclut
  le râtelier ; import rétrocompatible avec les anciens fichiers sans
  râtelier (fusion sans effacer le râtelier local).
- **NT-009** — Autocomplétion de l'arme : pendant la saisie d'une session
  (création/édition, prévue/réalisée, wizard de conversion), les noms du
  râtelier sont proposés (casse ignorée). La saisie libre reste toujours
  prioritaire — aucune complétion automatique ne l'écrase.

## Statistiques
- **NT-017** — Compteur de tirs par arme du râtelier, en toute dernière
  section de Statistiques > Avancé (sans graphe). Une ligne par arme, y
  compris à zéro ; total = somme des coups des sessions réalisées
  uniquement (essais compris), sessions prévues exclues.

## Plateforme et déploiement
- **NT-071** — Migration de la production de SQLite éphémère vers PostgreSQL
  Neon, avec Alembic comme source de vérité du schéma. Les connexions runtime
  et migration utilisent des URLs et des rôles distincts ; les migrations
  s'exécutent avant le démarrage du serveur et les procédures de sauvegarde,
  restauration et rollback sont documentées. Cette partie de la release
  produit v0.6.0 est portée par NexTarget-server v0.3.0.

## Qualité
- **NT-058** — Fakes de repository partagés pour les tests
  (`test/support/`) : `FakeSessionRepository` clone désormais chaque
  session lue et honore `preserveExistingSeriesIfEmpty`, comme
  `HiveSessionRepository` (correction d'un défaut de fidélité identifié en
  revue de code). `captureError()` pour tester une exception async sans
  laisser de travail en suspens entre deux tests.
- Règle **« aucun émoji »** (code, documentation, commits/PR) ajoutée à
  `AGENTS.md`, alignée avec `NexTarget-server`.

## Compatibilité
- Données locales Hive : nouvelle box additive `weapons` (migration v5,
  `Migration5CreateWeaponsBox`) — aucune migration destructive, aucune perte
  de données existantes.
- Le composant serveur v0.3.0 est inclus dans la release produit v0.6.0 ; les
  contrats d'API consommés par l'app restent inchangés.
